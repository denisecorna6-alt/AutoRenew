# Ajude a divulgar o AutoRenew

## O que é o projeto hoje

O **AutoRenew** é um projeto open source para acompanhar a validade de aplicativos instalados por sideloading no iPhone. A versão em desenvolvimento oferece cadastro manual de apps, histórico e alertas locais de expiração.

**Atenção:** a renovação automática real ainda não está pronta. A integração com SideSign, assinatura de IPA e instalação por Minimuxer continua em desenvolvimento. Não anuncie o projeto como renovador automático funcional, nem como produto oficial ou endossado pelo SideStore.

Código: https://github.com/denisecorna6-alt/AutoRenew

## Short English post

I'm building **AutoRenew**, an open-source iOS project to track sideloaded app expiration dates and send reminders. The current development version supports manual app tracking, history, and local expiration alerts; automatic signing/reinstallation through SideSign and Minimuxer is still in development. No fake renewal claims.

Contributors with Swift/iOS, code-signing, SideSign, or Minimuxer experience are welcome.

Repo: https://github.com/denisecorna6-alt/AutoRenew

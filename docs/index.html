Como instalar

  1. Configure o SideStore ou AltStore no iPhone.
  2. Baixe um IPA publicado ou um artefato de teste do GitHub Actions.
  3. Abra/compartilhe o arquivo IPA com SideStore ou AltStore.
  4. Conclua a assinatura com seu próprio Apple ID no fluxo oficial do instalador.

A versão atual ainda não implementa renovação real de certificados. Os IPAs produzidos pelo CI são unsigned (sem assinatura) e não podem ser instalados diretamente. A instalação exige assinatura válida e um método compatível. Não use Alpha/Beta como versão de produção.

Transparência e segurança

O AutoRenew é independente e não é afiliado à Apple. Não solicitamos nem armazenamos senhas Apple ID, códigos de autenticação ou chaves privadas. Não existe certificado gratuito universal ou permanente.
